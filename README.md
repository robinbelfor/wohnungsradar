# Wohnungsradar Wien

Privates Portal für Mietwohnungen in Wien, direkt von den Webseiten Wiener Makler.

- `main`: das Portal (`index.html`, Logo unter `assets/`), veröffentlicht über Netlify.
- `data`: die Wohnungsdaten (`listings.json`), nach jedem Scan aktualisiert. Pushes auf diesen Zweig lösen keinen Netlify-Deploy aus.
